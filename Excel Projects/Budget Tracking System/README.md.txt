## Budget Tracker Overview

### Problem It Solves
Most budget templates mix raw data with calculations, making them fragile and hard to maintain. 
This tracker separates **inputs**, **calculations**, and **outputs** for **clarity, scalability, and automation‑readiness**.

### Key Features
- **Transaction Tracking** - Date, category, account, amount, and tags.
- **Savings Goals** - Priority, deadlines, target vs current savings.
- **Variance Analysis** - Budget vs actual spending per category.
- **Forecasting** - Rolling averages & predictive spend using `FORECAST.LINEAR`.
- **KPIs** - Saving rate, burn rate, net cashflow.

## How to Use
1. **Input Transactions** in the `Transactions` and `Monthly Data` sheet - use dropdowns for consistency.
2. **Review KPIs** in the `Summary` and `Dashboard` sheet.
3. **Check the Dashboard** for real‑time visual insights.
4. **Update Goals** in the Goal Tracker tab.
5. Save & version control through GitHub.
